Все 6 находок F1–F6 закрыты и слиты в этом окне:
- **F1**: `anti_rec` окно теперь закрывается ДО вызова callback-capable
  оригиналов (ShellExecute*/CoCreateInstance*/SendMessage*) — раньше
  вложенный хук внутри guest-reachable кода видел ещё активную suppression и
  пропускал проверку. `com_guard.rs` распался в директорию по layout-guard.
- **F2**: ShellExecuteEx* теперь классифицирует `fMask` (IDLIST/CLASSNAME/
  CLASSKEY/INVOKEIDLIST/DOENVSUBST) — раньше alternate-resolution пути
  (PIDL, class override, env-subst) обходили строковую проверку полностью.
- **F3**: HWND classifier в `ui_guard.rs` заменён с boolean на enum
  (`NoTarget`/`SpecialDest`/`Unknown`/`OwnSandbox`/`Foreign`) — раньше NULL и
  failed-lookup оба трактовались как "allowed"; теперь Unknown и
  SpecialDest(HWND_BROADCAST и др.) явно денайятся.
- **F4**: install_hooks теперь разделяет guards на MANDATORY (com/service/
  shell — missing export = `Err`, DllMain FALSE) и OPTIONAL (ui/WinRT-siblings
  — буферизуются через уже существующий S10 degraded-init механизм). Реальный
  баг найден и починен воркером: unused import после рефакторинга.
- **F5**: в работе на момент чекпоинта — SCM access-mask логика (denylist по
  агрегату `*_ALL_ACCESS` вместо конкретных битов + generic-rights mapping).
- **F6**: DACL policy-pipe сужен (client ACE без `FILE_CREATE_PIPE_INSTANCE`),
  честно задокументирован no-op на практике (client/server пока делят один
  SID — реальный эффект появится только с отдельной identity из R04-D).
  **Реальный найденный и починенный баг**: собственный интеграционный тест
  F6 держал открытым первый (`is_first=true`) instance pipe необслуженным
  во время попытки клиента подключиться — Windows может подключить
  `CreateFileW` к ЛЮБОМУ живому instance того же имени, не обязательно к
  тому, который сервер ждёт через `ConnectNamedPipe`; из-за этого клиент
  иногда попадал на необслуженный instance → deadlock. Починено закрытием
  первого instance сразу после создания второго, до старта серверного потока.
  Стабильность подтверждена 3 прогонами подряд.
